# Painted Geologist cave backdrop — R137

The fixed Geologist cave uses one hand-painted limestone environment. The background replaces the flat color blocks, hard strata bands, and broad spotlight polygons. The fossil, trays, crystals, actors, touch layout and activity visibility still come from the existing game. The shared curtain-call artwork remains a separate role.

One built-in ImageGen call returned an opaque 1672×941 native painting. Aseprite cropped the continuous 1664×936 playfield into two 832×936 tiles. The exported tile pixels match the native source. The tiles use lossless imports and no mipmaps. This is one fixed-screen artwork and does not claim multi-screen 2K coverage.
