# PC round: commercial reference shortlist

Status: pending. None of these titles was installed when the owner's PC came online on 2026-11-01. Prepared by the research agent from fetched store and publisher pages; nothing here was installed or tested.


Target: the owner's Windows desktop (Ryzen 5 3600, mouse). Played later by
computer use, one game at a time. Nothing here has been installed or tested;
install routes come from the store pages cited in reference_map.md.

## Install routes

| Route | What it needs | Notes | Source |
|---|---|---|---|
| **Steam** | Steam client, Windows 10 or later | Native Windows; mouse is the normal input | Steam pages cited per title |
| **Google Play Games on PC** (Google's own app) | Windows 10 v2004+, SSD with 10 GB free, 4 physical cores (the 3600 has 6), 8 GB RAM, Intel UHD 630-class GPU or better, Windows admin account, **hardware virtualization on** (on a Ryzen board this is SVM Mode in the BIOS) | Use only for titles whose Play listing says "Available on: Android, Windows". Out of beta since 23 September (2025 by context); 200,000+ titles. Paid apps: "a single purchase unlocks both" applies only to "select paid titles" | [Play Games FAQ](https://play.google.com/googleplaygames), [Android Authority](https://www.androidauthority.com/google-play-games-pc-no-longer-beta-general-availability-3599973/) |
| **BlueStacks 5** with the owner's Google account | Windows 10+ recommended, 8 GB RAM recommended, admin account, virtualization enabled | For Android titles not listed for Windows. Sign in to Google Play inside BlueStacks with the same account used for purchases and subscriptions. Mouse click = one-finger tap; mouse drag = one-finger drag, which matches the one-finger audience | [BlueStacks requirements](https://support.bluestacks.com/hc/articles/360056129211) |
| **Microsoft Store** | Windows 10/11 | Only legacy kids' apps found (Sago Mini Babies, Dr. Panda's Hospital/Daycare). Current installability UNVERIFIED | MS Store pages cited per title |
| Windows Subsystem for Android / Amazon Appstore | none | **Do not use**: Android apps on Windows 11 "stop functioning after March 5, 2025" | [Windows Central](https://www.windowscentral.com/software-apps/windows-11/microsoft-is-killing-support-for-running-android-apps-on-windows-11) |

Setup order on the PC: (1) enable SVM in BIOS; (2) install Steam; (3) install
Google Play Games on PC; (4) install BlueStacks 5. If Google Play Games and
BlueStacks conflict over Hyper-V, BlueStacks publishes a separate
"Hyper-V enabled" build ([BlueStacks](https://support.bluestacks.com/hc/en-us/articles/4415238471053)).
Subscriptions bought on Google Play under the owner's account apply inside
BlueStacks because it uses the same Play account (standard Play behaviour;
not tested here).
