# Series quality gates

## Character gate

- Correct canonical face, age, species and body proportions.
- Hair, wardrobe, accessories and color placement unchanged.
- Correct relative scale beside recurring cast.
- No duplicated limbs, fused bodies or unintended legs/feet/shoes.
- Concept or pending characters are not presented as canon.

## Style gate

- Matches approved base-video linework, shading, background finish and motion cadence.
- Reads as polished 2D television-animation storybook art.
- No photorealism, plastic CGI, modern flat-vector simplification or style mixing.

## Continuity gate

- Start state matches accepted previous ending frame when action is continuous.
- Screen direction, eyelines, wardrobe, object state and emotional beat are correct.
- Recurring location geography and landmark sides remain fixed.
- Camera/light changes are authored rather than accidental.

## Motion gate

- Single clear action with readable start and end.
- Stable anatomy and design throughout motion.
- Weight, timing and effects match the base-video cadence.
- No uncontrolled morphing, texture crawling, object popping or camera shake.
- Duration is 15 seconds or less.

## Child-audience gate

- Emotion and action are readable without text.
- Threat remains playful and non-traumatic.
- No injury, cruel failure, abandonment or frightening transformation.
- Important objectives have clear visual and later approved audio support.

## Delivery gate

- Native download preserved and named.
- Attempt recorded in the sequence ledger.
- Reference versions recorded.
- Watermark/provenance markings are not removed or obscured.
- Final assembly is 16:9 and prepared for the project's 1280×720 game target without cropping essential action.
