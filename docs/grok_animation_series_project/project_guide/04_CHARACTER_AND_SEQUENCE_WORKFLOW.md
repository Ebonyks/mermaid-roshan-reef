# Character and sequence workflow

## New-character onboarding

1. Register the name and stable ID as `REFERENCE_PENDING`.
2. Add owner-approved source art without modification.
3. Record immutable traits and explicitly unknown traits.
4. Generate neutral front/three-quarter/rear studies in Image Quality mode.
5. Human-select one coherent turnaround family.
6. Generate expression and action tests.
7. Test the character beside Mermaid Roshan for relative scale and style compatibility.
8. Change status to `APPROVED` only after identity, scale and style pass.

## New-sequence workflow

1. Create a module from `templates/SEQUENCE_MODULE_TEMPLATE.md`.
2. List cast, location, props, wardrobe state and time-of-day.
3. Select two to four relevant base-video style stills.
4. Create one anchor still per authored camera setup.
5. Record screen direction and ownership continuity.
6. Generate each shot at no more than 15 seconds, generally 6 seconds plus handles.
7. Use accepted ending frames for continuous-action handoffs.
8. Review before starting dependent shots.
9. Assemble externally; preserve native Grok downloads and provenance markings.

## Continuity dimensions to track

- Character: face, age, hair, costume, accessories, tail, scale.
- Topology: limb count, finger structure, tail separation, prop contact.
- Relationship: screen side, gaze target, physical distance, emotional beat.
- Object state: owner, position, open/closed, damaged/intact, carried/set down.
- Location: geography, entrances, path direction, landmark positions.
- Camera: lens feeling, height, angle, movement, eyeline.
- Light/time: direction, warmth, exposure and atmosphere.
- Motion: starting pose, ending pose, speed, weight and cadence.

## Sequence inheritance rule

The next shot inherits only what the script says remains continuous. A cut may change camera angle, but it must not change character design, wardrobe, object state, geography or time-of-day unless the script explicitly does so.
