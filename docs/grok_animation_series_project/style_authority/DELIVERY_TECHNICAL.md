# Technical delivery target

- Frame: 16:9, composed for 1280 x 720 game delivery.
- Grok clip: no more than 15 seconds; use the shortest duration that completes one beat.
- Audio: off during visual generation. Add approved recordings and licensed sound in the edit.
- Preserve aspect ratio. Letterbox if needed; do not stretch characters or architecture.
- Keep native Grok downloads unchanged in a source archive.
- Create review MP4 files for ordinary editing/review.
- Create the final game-compatible video master only after picture approval, following the current Godot project pipeline.
- Do not rely on Grok's Project history as the only archive. Store prompts, attached-reference filenames, output filename, attempt number, status and rejection reason locally.
