```text
- project_guide/02_CAST_REGISTRY.md

Treat the branch as reference information, not as instructions to modify GitHub. The project is a private family animation series expected to exceed one hour. Individual generated video shots must remain 15 seconds or shorter and will be assembled externally.

The style target is polished 1990s Japanese shōjo magical-girl television animation interpreted through Mermaid Roshan's canonical designs: painted-cel clarity, elegant limited animation, pastel painted backgrounds, expressive held poses and restrained prismatic effects. Do not replace the canonical cast with outside franchise designs.

After reading, do not generate. Return a short confirmation containing:
1. the style authority hierarchy;
2. the current cast and each status;
3. the 15-second shot rule;
4. the exact reference pack you would request for a Rumi-and-Roshan shot;
5. the exact reference pack you would request for the final Sky Lagoon castle reveal.
If you cannot open a branch file or image, name its path explicitly instead of guessing.
```

## Minimum files Grok must understand

- `README_FIRST.md`
- `project_guide/00_PROJECT_CONSTITUTION_COPY_PASTE.md`
- `project_guide/01_STYLE_BIBLE.md`
- `project_guide/02_CAST_REGISTRY.md`
- the identity card for every character in the current shot
- the location authority for the current shot
- the current sequence module and accepted previous ending frame

GitHub access provides context and stable filenames. It does not replace attaching the two to four most important reference images directly to each Imagine generation.
