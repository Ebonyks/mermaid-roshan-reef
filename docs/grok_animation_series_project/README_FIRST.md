# Mermaid Roshan Animation Series — Grok Project Guide

This is the durable Project guide for **an hour or more of Mermaid Roshan animation**, not a single cinematic. The opening flight is included only as the first production module and a source of established visual direction.

This Git branch is the authoritative Grok handoff. The Downloads copies are snapshots only. Use the documents and reference art in this directory whenever they disagree with an older handoff.

## Project purpose

Maintain a growing Mermaid Roshan animated world across many sequences, locations, and characters while using Grok Imagine's short-clip generation workflow. The Project must preserve:

- character identity, age, anatomy, wardrobe and scale;
- the established 2D storybook/anime rendering language;
- location geography and recurring props;
- relationship behavior, screen direction and hand/object ownership;
- accepted shot-to-shot continuity;
- stable names and reference authority as the cast expands.

Grok clips remain limited to 15 seconds, but the Project itself is organized as an expandable series library. Episodes and sequences are assembled from short accepted shots.

## Start here

1. Open `GROK_START_HERE.md` and give Grok the dedicated branch link.
2. Create one Grok Project manually: `Mermaid Roshan — Animation Series`.
3. Add the documents under `project_guide/` to the Project or paste their copy blocks as directed.
4. Add `style_authority/BASE_VIDEO_REQUIRED.md`, then manually upload the existing base video and representative stills when available. The base video itself was not found in the repository, so this branch does not pretend to contain it.
5. Add the folders under `characters/` to the Project library. Rumi's local Violet Tide art is included as approved private-project canon, together with the owner-supplied Roshan/Rumi relationship sample.
6. Use `modules/opening_flight_to_sky_lagoon/` as the first sequence module, not as the global Project definition.
7. For every new episode, duplicate `templates/SEQUENCE_MODULE_TEMPLATE.md` and create a new module folder.

## Folder map

- `project_guide/` — permanent series constitution, style rules, cast registry, continuity workflow and copy/paste prompts.
- `style_authority/` — base-video ingestion instructions and existing visual-direction documents.
- `characters/` — expandable per-character reference folders and identity cards.
- `locations/` — reusable Sky Lagoon authorities; add future places here.
- `modules/` — episode/sequence-specific scripts, prompts and ledgers.
- `templates/` — new-character and new-sequence onboarding templates.

## Core operating principle

The Grok Project is an organized continuity library, not guaranteed automatic visual conditioning. Keep permanent bibles in the Project, but attach the exact character, style, location and previous-frame authorities required for each generation. Use two to four references normally; never attach the entire cast to every shot.
