# Violet Tide Mermaid

> Historical development record. The owner has since designated this visual design as **Rumi — APPROVED_PRIVATE_CANON** for the private family animation project. The current authority is `IDENTITY_CARD.md`; the original status language below is retained only as provenance.

Working name: **Violet Tide**

Status: **IP-hold visual prototype**. This pass deliberately keeps recognizable
inspiration from the user-supplied reference character while beginning the move
toward a project-owned identity. It is suitable for private playtesting and
design iteration, but it is not represented as legally cleared original
character art and should not be used for merchandising or public marketing.

## Four-year-old readability

- One unmistakable silhouette: large violet braid, short sea-jacket, long
  turquoise-to-lavender tail, broad coral split fin.
- Friendly face and open hands; no weapon, fail-state imagery, or threatening
  expression.
- Large color blocks and high-contrast navy edges remain readable at roughly
  160 px character height on a phone.
- Slow, broad animation poses communicate hover, greeting, and swimming without
  text.

## Original identity seeds

- Gold three-shell clasp.
- Coral-comet, shell, and wave jacket motifs with no borrowed logos or text.
- Coral-pink fin and turquoise/lavender scale gradient.
- "Cool older-sister" role: confident, reassuring, and playful rather than
  combative.

## Starter animations

The `violet_tide_animations.png` atlas uses a 4 x 2 grid of 256 x 384 cells:

| Animation | Cells | Suggested use |
| --- | --- | --- |
| `idle` | top row, columns 1-2 | Gentle two-frame hover at 1.5 fps |
| `wave` | top row, columns 3-4 | One friendly greeting at 2 fps |
| `swim` | bottom row, columns 1-4 | Four-frame travel loop at 5 fps |

`violet_tide_sprite_frames.tres` packages those cells as ready-to-load Godot
`SpriteFrames`. The separate `violet_tide_full_body.png` is the high-detail
dialogue, roster, and story-card sprite.

## Identity migration path

1. **Prototype:** keep the purple braid, sharp brows, and performer jacket so
   the child recognizes the intended inspiration.
2. **Separation pass:** change the braid construction into an asymmetrical
   tidal-knot silhouette, enlarge the three-shell clasp, simplify the jacket
   panels, and replace the star earrings with an original shell shape.
3. **Ownership pass:** establish a new name, family role, voice, color rhythm,
   and signature action; redraw the face proportions from the project's own
   character language without reference stills.
4. **Clearance gate:** perform an owner/legal visual-comparison review before
   any public promotion or merchandising.

## Integration note

This asset pack does not add the character to save data, a quest, or the live
roster. A core gameplay role needs an owner-approved name, voice key, objective,
visual pointer, and save-compatible defaults before integration.
