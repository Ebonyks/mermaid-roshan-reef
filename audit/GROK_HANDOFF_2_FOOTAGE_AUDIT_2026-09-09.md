## Protocol audit and implementation

The existing MASTER formula already forbids the observed substitutions. This is principally a failure to make those controls executable and to review across shots. The older C07 S01/S02 KEEP rows judged stability in isolation; C06 S02 similarly retained a stream from the wrong seahorse. The later edit review identified some bad inserts and removed them in V02/V03, but omission did not repair the source or make future recaps safe. Draft shot cards used location paths under IMAGE_1 despite a missing-opening status, and could report no blocking findings. Handoff 2 makes missing IMAGE_1 literally null, attaches blockers, separates source authority from opening approval, and prevents the repair queue from granting readiness.

The new packet binds both seahorse states, all room authorities, character/object sources, runtime-boundary references and narrative boards in an archive, with only a small per-job binding plan. Shared room locks connect discovery/restoration/recap. Priority cards specify the actual cast so an empty-room job is not fed unrelated characters. The shot matrix preserves historical verdicts and exact selected-edit variants, with new GH2 findings taking precedence in this repair commission.

The validator checks payload hashes, complete historical shot coverage, bounded image counts, null-opening blockers, forbidden board bindings, dependency IDs/cycles and status separation. Mutation tests exercise common bypasses. It does not evaluate pixels or approve an opening. Finished execution cards must still pass the existing Imagine validator, and final frames the cinematic validator.
