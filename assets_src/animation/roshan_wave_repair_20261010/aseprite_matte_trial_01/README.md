# Aseprite boundary alpha recovery pilot

Status: source-only matte/detail cleanup study for native LTX frames14,26 and40. Variant04 is the preferred local matte candidate. It does not repair the underlying damaged hand in frame26 or source focus/proportion failures, and no complete wave or owner/device/child/runtime acceptance is claimed.

Sources are byte-exact copies of native640_01/take_01/native_frames/0014.png,0026.png and0040.png. Originals remain untouched. Aseprite1.3.18.4-x64 performs every pixel edit and resample; Python performs only decoded-pixel measurement, hashes and metadata. No GPU inference, paid API call or campaign generation take is used.

The baseline flood removes only neutral RGB pixels with channel spread≤10 and minimum channel≥205 that connect to the outer image boundary. All other pixels initially retain the source RGB. Closed pale neutral highlights stay protected.

Edge recovery is restricted to a two-pixel band adjacent to that background/figure boundary. It searches actual same-frame foreground neighbors within a Euclidean radius of3px and solves C=aF+(1-a)B, where C is the observed matted source color, F is an existing painted interior color and B is a local median of high-confidence neutral background samples. The measured backdrop varies near236–238, so a fixed broad color key is avoided. Accepted fits reconstruct straight-alpha RGB=F and alpha=a on the same complete cel. This is boundary unmatting, with all color reconstruction and criteria declared.

The variants retain their intermediate outputs:

- The root folder is variant01: strict5-unit RGB fit, alpha minimum0.025. Too many foreground samples were still gray antialias pixels, leaving a speckled halo.
- variant_02 permits a10-unit RGB fit and alpha minimum0.04. This alone did not adequately distinguish gray edge pixels from real paint.
- variant_03 additionally requires actual foreground samples at least2px inside the retained figure, with either channel spread≥20 or a dark channel≤140. Closed neutral highlights are explicitly protected. This materially reduces the fringe without morphological shrinkage or expansion.
- variant_04 adds three visually classified enclosed background seeds in the existing hair-loop gap: frame14 at(459,226), frame26 at(454,218), frame40 at(457,219). The approved_K0 RGBA identity source depicts this same gap as transparent. Only the corresponding connected neutral islands are removed; remaining closed pale highlights stay pixel-exact. These seed coordinates apply only to the three inspected sources and must be revalidated for other drawings.

Each variant retains native RGBA PNGs, a connected-background baseline, one uniform whole-image reduction from640×896 to200×280, and translation(55,-10) into the256px cell. There is no nonuniform scaling, pasted hand, part layer, independently warped piece, erosion or dilation.
