# Persistent B-roll refinement exchange

Store each return under `reshoots/<B-SHOT-ID>/<ATTEMPT>/` in the private media repository on an identified durable branch. Use `REQUEST.json`, `RETURN.json`, `REVIEW.json` and native media. Every response links the preceding immutable request commit/hash. Never overwrite or relabel an old rejected take.

The request names the paired A shot and consumes its existing lineage/cap unless an explicit owner decision authorizes a different budget. Source HOLDs are inherited. Naming a new B angle is not a bypass. Recheck the latest A request/return history before spending another attempt: this package freezes the September 19 parent, not future approvals or new consumption.

First-frame preparation and motion generation are separate. Show every complete alternate candidate to the owner with exact filename and SHA-256. Record the approval receipt, complete 2–4 binding roles and recipient access, then run the canonical Imagine validator before motion. The provided empty return template cannot authorize work.

Reviewer feedback includes the observed defect, native start/end frame, corresponding game/source reference, required reconstruction, retained good spans and whether a whole-shot or individual-frame replacement is required. Parent and B state/cast remain fixed unless the owner explicitly changes the event.

After every review revision, commit/push the full changed package, verify exact remote bytes and publish immutable links. Local-only reports are not handoffs. No scheduler or unattended generation was created by this package; it supplies the durable exchange format for future authorized rounds.
