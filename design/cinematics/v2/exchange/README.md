# Exchange (hashes only)

Media bytes never land here. Use the private repo
[Ebonyks/mermaid-roshan-grok-videos](https://github.com/Ebonyks/mermaid-roshan-grok-videos)
plus a GitHub release. This folder stores REQUEST / RETURN / REVIEW JSON.

```text
exchange/attempts/<SHOT_ID>/A00N/
  REQUEST.json
  RETURN.json
  REVIEW.json
```

Copy templates from `../templates/`. Attempt numbers are A001, A002, A003.
Stop at three or HOLD. A RETURN is a receipt, not acceptance.

Do not create these folders until a CARD is handed to Grok. Empty attempt
trees are noise.
